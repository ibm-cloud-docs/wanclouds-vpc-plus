# About {{site.data.keyword.vpc-plus-migration}}
{: #about-wanclouds}

## What is {{site.data.keyword.vpc-plus-migration}}?
{: #what-is-vpc-migration}

{{site.data.keyword.vpc-plus-migration}} is a third-party, software-based migration-as-a-service solution for migrating workloads and other related components from {{site.data.keyword.cloud}} classic infrastructure to your {{site.data.keyword.cloud_notm}} Virtual Private Cloud (VPC).
{{site.data.keyword.vpc-plus-migration}} allows you to discover and choose resources for migration, and create and set up those resources in your VPC environment. You can also run and manage your VPC environment from within the tool.

{{site.data.keyword.vpc-plus-migration}}, which is managed by Wanclouds, follows industry best practices to ensure that its application tool is secure and protects your sensitive information.

## What resources can be migrated?
{: #what-resources-can-be-migrated}

Classic Cloud Native Resources:
* Subnets
* Virtual server instances
* Dedicated hosts
* Storages (Primary, Secondary, NFS, ISCSI, Block)
* Security groups
* Load balancers
* Firewall (ACL) configuration
* VPN configuration
* SSH keys
* Public gateway

IBM Kubernetes Clusters + ROKS:
* PVs, PVCs 
* Deployments 
* Config maps 
* Services 
* Secrets 
* Namespaces 
* Daemontsets 
* Replicasets 
* Image streams 
* Build configs

VMWare (Self-Managed and Provider Managed):
* vCenter
* ESXi 
* VMWare Virtual Machines
